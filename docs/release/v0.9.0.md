# ADLC 0.9.0

ADLC 0.9.0 establishes the first public-beta candidate for a schema-backed,
approval-aware agentic development lifecycle.

## What is included

- One canonical public `adlc` skill with Build, Fix, and read-only Review loops.
- Transactional skill installation for supported provider targets, with drift
  detection that preserves changed or unknown user files.
- Schema-valid Build Briefs, workflow state, approvals, retry bounds, and
  completion-audit contracts exposed through the CLI and MCP surfaces.
- A deterministic public Fix benchmark with three primary runs and three
  independent replay runs on the same published fixture.
- Evidence-derived provider support claims, strict documentation checks, and a
  reproducible wheel and source distribution release path.

## Evidence boundary

The recorded beta claim applies only to Codex Fix using the named provider,
model, harness, source commit, fixture, and evidence bundle in the provider
support matrix. Other providers and loops are not upgraded by this release.
Local candidate preparation does not prove registry availability, future model
behavior, or successful external deployment.

## Publication boundary

These notes become public release notes only when the immutable `v0.9.0` tag,
the exact packet SHA-256, a schema-valid human `release_publication` approval,
and all protected GitHub environments have passed. Until then, every PyPI,
GitHub Release, Pages, and launch action remains pending.

## Upgrade and rollback

Install the exact published `adlc==0.9.0` package only after its artifact digest
matches the approved release packet. PyPI artifacts are immutable; a defect is
corrected with a new version. Because this is the first public package release,
the rehearsal restores the candidate from immutable local test-index bytes and
records that no prior public version exists.

`doc_honesty_section`: These are final-form candidate notes, not evidence that
external publication has happened.

`no_overclaim`: ADLC 0.9.0 does not claim universal provider support, security
certification, telemetry-backed adoption, or guaranteed future agent behavior.

`limitations`: The initial release covers one PyPI project, one GitHub
repository, one Pages site, and the evidence-scoped support rows named above.
