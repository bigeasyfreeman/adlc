# Internal Engineering Pack Register

Load only the row applicable to the selected command and task. Deterministic responsibilities named below must be executed by the kernel command, not reproduced as prose judgment.

| Applicability signal | Migrated legacy sources | Bounded contract |
| --- | --- | --- |
| Repository research and existing conventions | `codebase-research`, `graph-research`, `dark-code-audit`, `paved-road-registry` | Start from repository instructions and declared architecture maps, trace evidence to files, and separate observed from inferred relationships. |
| Planning, context assembly, architecture, reuse | `architecture-pattern`, `codegen-context`, `context-layers`, `reuse-analysis` | Prefer existing paved roads, bound loaded context, state tradeoffs, and record missing decisions. |
| Tests and implementation discipline | `qa-test-data`, `spec-to-tests`, `tdd-enforcement`, `ldd-enforcement`, `test-strength`, `mutant-materiality-judge` | Establish the expected red reason, make the smallest scoped change, run the exact verifier, and evaluate whether tests detect material faults. |
| Independent judgment | `eval-council`, `section-policy-judge`, `specificity-judge`, `verifier-semantic-judge` | Use independent evidence, explicit criteria, and a clear pass/revise/block result; never substitute consensus for the declared verifier. |
| Mechanical gates | `brief-clarity-judge`, `comprehension-gate`, `definition-of-done`, `stop-slop`, `slop-judge` | Run `bin/adlc clarity-gate`, `bin/adlc operator-comprehension-gate`, `bin/adlc completion-audit`, or `bin/adlc slop-gate` as mapped. Do not emulate their result in prose. |
| Learning | `feedback-loop`, `learning-capture`, `learning-refresh` | Use `command-learn.md`; retain provenance, redaction, health, and human-review boundaries. |

`execute-trade` is deliberately excluded. It is retained only as legacy source evidence during beta and is never an applicable ADLC internal pack.
