# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately through a
[GitHub Security Advisory](https://github.com/bigeasyfreeman/adlc/security/advisories/new).
Do not include credentials, exploit details, or sensitive target-repository data
in a public issue.

Include the affected version or commit, the relevant adapter or command, a
minimal reproduction, expected impact, and any known mitigation. You should
receive an initial acknowledgment within five business days. Confirmed issues
will be coordinated privately until a fix and disclosure plan are ready.

## Support Boundary

The `main` branch receives security fixes. After releases are tagged, the latest
tagged release will receive fixes as well. Runtime adapters labeled
experimental are fail-closed and are not claims of provider support. Provider
credentials remain the operator's responsibility and must not be committed to
ADLC or target repositories.
